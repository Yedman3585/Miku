# Miku Runner для Arduino Mega (самостоятельная версия)

Игра целиком на Mega, без ПК: экран 3.2" TFT-шилд (480×320), две кнопки, динамик.
Логика и физика те же, что в `miku_runner.py` (проверено на ПК ботом: `tools/test_game_host.cpp`).

> Статус: **скелет**. Компилируется под Mega 2560 (156 КБ флеш из 256, 1,2 КБ ОЗУ из 8),
> но на железе ещё не запускался — см. «Первый запуск».

## Что нужно
- Arduino Mega 2560 + шилд 3.2" TFT 480×320 (втыкается в Mega)
- 2 кнопки, динамик (пассивный/пищалка) + резистор 100–220 Ом
- Arduino IDE, библиотеки: **MCUFRIEND_kbv** (поставит и Adafruit GFX)

## Подключение
| Что | Пин Mega | Куда |
|---|---|---|
| Кнопка «прыжок» | D2 | вторая ножка → GND (подтяжка внутри) |
| Кнопка «пригнуться» | D3 | вторая ножка → GND |
| Динамик | D6 | через 100–220 Ом → GND |

Если шилд занимает эти пины, поменяйте их в `config.h` (`PIN_BTN_JUMP`, `PIN_BTN_DUCK`, `PIN_SPEAKER`).

## Первый запуск
1. Откройте `miku_runner_mega.ino`, плата **Arduino Mega or Mega 2560**, загрузите.
2. Откройте Serial Monitor (115200): первая строка `LCD id=0x....` — драйвер вашего экрана.
   Если там `0x0000`/`0xFFFF` или экран белый — драйвер не определился, напишите id мне.
3. Картинка вверх ногами → `LCD_ROTATION` в `config.h` поменять 1 ↔ 3.
4. Играть: кнопка «прыжок» (держи дольше — выше), «пригнуться» — под летающим луком.

## Устройство
- `game.h / game.cpp` — чистая логика (без Arduino), проверяется на ПК
- `render.cpp` — отрисовка на MCUFRIEND_kbv: фон не хранится в памяти, «стирание» = перерисовка куска фона из формул
- `sound.h` — звук без блокировки (`tone()`): эффекты + мелодия
- `sprites.h` — спрайты Miku/лука в RGB565 во флеш-памяти. **Генерируется**:
  `python tools/export_sprites.py` (из `assets/`); `--height 80` — Miku поменьше, меньше флеш
- `config.h` — пины, размеры, физика

## Проверка логики на ПК
    g++ -O2 -std=c++11 -I arduino/miku_runner_mega tools/test_game_host.cpp arduino/miku_runner_mega/game.cpp -o test_game
    ./test_game

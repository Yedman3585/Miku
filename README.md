# Miku Runner

Бегалка в стиле динозаврика Google: Miku бежит и прыгает через лук. Играть можно с клавиатуры
или с джойстика Arduino; картинка одновременно идёт в окно на ПК и на OLED 128×64.

## Запуск
    pip install -r requirements.txt
    python miku_runner.py              # с Arduino (порт ищется сам)
    python miku_runner.py --no-serial  # только клавиатура
    python miku_runner.py --port /dev/cu.usbserial-XXXX   # порт вручную

Управление: прыжок — кнопка джойстика / ↑ / Пробел / джойстик вверх (дольше держишь — выше).
Пригнуться — ↓ / джойстик вниз. TAB — превью OLED в окне, M — звук, F — полный экран.

## Как это устроено
    ПК (Python)                                   Arduino (C++)
    ┌───────────────────────────┐   USB (Serial)   ┌──────────────────────┐
    │ игра: логика + физика     │ ◄── J x y btn ── │ читает джойстик      │
    │ рисует кадр 128×64 (1 бит)│ ── 1024 байта ─► │ кладёт в буфер OLED  │
    │ + цветное окно + музыка   │ ◄──── "F" ────── │ показывает, шлёт "F" │
    └───────────────────────────┘                  └──────────────────────┘
Следующий кадр уходит только после "F", поэтому ничего не теряется и скорость сама подстраивается.

## Arduino
1. Открыть `arduino/miku_runner_oled/miku_runner_oled.ino`, поставить библиотеку "Adafruit SSD1306".
2. Подключение: OLED SDA→A4, SCL→A5, VCC→5V, GND→GND; джойстик VRx→A0, VRy→A1, SW→D2.
3. Загрузить скетч. Скорость порта 500000; если оставить старую прошивку — запускай с `--baud 115200`.
Если вверх/вниз перепутаны — `--flip-y`; если картинка на OLED вверх ногами — `--flip-oled`.

## Файлы
- `miku_runner.py` — вся игра и связь с Arduino
- `pixel_miku.py` — нарисованные вручную 1-битные спрайты для OLED (правятся прямо буквами)
- `make_sprites.py` — нарезка цветных спрайтов из `assets/src/` (нужен scipy, запускать только при смене картинок)
- `assets/` — готовые спрайты. Свои фон-видео и музыку клади сюда: `splash.mp4`, `music.mp3|ogg|wav`
- `miku_game.py`, `make_splash.py`, `arduino/miku_joystick_oled/` — старый арканоид, не нужны для Runner
